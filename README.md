# MiBodega Móvil · Semana 01

Primera app híbrida con **Ionic + Angular + Capacitor**.

```bash
npm install        # 1. descarga las dependencias (crea node_modules/)
ionic serve        # 2. abre la app en el navegador (http://localhost:8100)
```

Manual completo paso a paso: `Manual_Semana01.pdf`.
